# Tsedo's math · XII ангийн математикийн сургалтын платформ

Монгол хэл дээрх, Python стандарт сан болон SQLite ашигладаг локал веб платформ. Бүртгэл, нэвтрэлт, багш/сурагчийн эрх, анги, даалгавар, бодлого, шалгалтын үр дүн сервер талд хадгалагдана.

## Windows дээр ажиллуулах

Python 3.10+ шаардлагатай. PowerShell:

```powershell
Set-Location "C:\Users\user\OneDrive\Ажлын тавцан\Tsedo's math"
$env:HOST = "127.0.0.1"
$env:PORT = "8000"
$env:TEACHER_INVITE_CODE = "ӨӨРИЙН-НУУЦ-КОД"
& "C:\Users\user\AppData\Local\Programs\Python\Python312\python.exe" server.py
```

Хэрэв энэ Python зам танай компьютерт өөр бол суулгасан Python-ийн `python.exe`-ийн замаар солино. `TEACHER_INVITE_CODE`-ийг санамсаргүй, бусдад дамжуулах кодоор өөрчил; ажиллуулах цонхонд эхний багшийн бүртгэлд хэрэглэнэ. `HOST`, `PORT`-ийг тохируулсны дараа `http://127.0.0.1:8000/`-г нээ. Терминалын цонх сервер ажиллаж байх хугацаанд нээлттэй байна. `index.html`-г шууд нээхэд API ажиллахгүй.

Дахин асаахад ижил багшийн invite код болон SQLite өгөгдөл хэвээр байна. Өгөгдлийн сан анхдагчаар `instance/platform.sqlite3`; `DATABASE_PATH`, `HOST`, `PORT`-оор өөрчилж болно. `python -m unittest discover -s tests -v` хөгжүүлэлтийн туршилтыг ажиллуулна. Туршилт бүр тусдаа түр SQLite сан ашигладаг; үндсэн санг өөрчлөхгүй.

### Багш, сурагчийг ижил Wi-Fi сүлжээнээс холбох

1. Сервер ажиллаж байгаа PowerShell цонхонд `Ctrl+C` дарж зогсооно.
2. Төслийн хавтсанд `start_lan.ps1`-ийг ажиллуулна:

   ```powershell
   Set-Location "C:\Users\user\OneDrive\Ажлын тавцан\Tsedo's math"
   .\start_lan.ps1
   ```

3. Скриптийн хэвлэсэн `http://192.168...:8000/` хаягаас өөрийн Wi-Fi IPv4 хаягийг сонгоно. Багш болон сурагчид өөрсдийн төхөөрөмж дээр энэ хаягийг нээнэ. Серверийн компьютер асаалттай, PowerShell цонх нээлттэй, төхөөрөмжүүд ижил хувийн Wi-Fi сүлжээнд холбогдсон байх ёстой. `127.0.0.1` нь зөвхөн серверийн компьютероос нээгдэнэ.
4. Багш `Нэвтрэх` → бүртгүүлэх хэсэгт багшийн эрх сонгож, серверийн консолд хэвлэсэн урилгын кодоор **нэг удаа** бүртгүүлнэ. Нууц кодыг зөвхөн багшид өгнө. Серверийг дараа дахин асаахад өөр багш бүртгүүлэх боломж хэвээр байлгах бол ижил `TEACHER_INVITE_CODE`-ийг асаалт бүрт тохируулна. Сурагч урилгын кодгүйгээр өөрийн эрхээр бүртгүүлнэ.
5. Windows Firewall холболтыг хаавал PowerShell-ийг администратороор нээгээд дараах командыг нэг удаа ажиллуул. Энэ нь зөвхөн хувийн сүлжээний дотоод төхөөрөмжүүдээс TCP 8000 портыг нээнэ:

   ```powershell
   New-NetFirewallRule -DisplayName "Tsedo's math LAN" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private -RemoteAddress LocalSubnet
   ```

Энэ горим нь зөвхөн итгэмжлэгдсэн хувийн Wi-Fi/LAN-д зориулагдсан; HTTP, хөгжүүлэлтийн сервер ашигладаг. Router дээр port forwarding бүү тохируулж, нийтийн Wi-Fi-д ажиллуулахгүй. Интернэтээр нийтэд ашиглуулахын тулд HTTPS, домэйн, production хост болон серверийн тохиргоо шаардлагатай.

### Интернэтээр хаанаас ч ашиглуулах (HTTPS)

Төслийн `Dockerfile`, `docker-compose.yml`, `Caddyfile` нь нийтийн VPS дээр HTTPS-тэй ажиллуулахад бэлэн. Байнгын линк гаргахын тулд домэйн болон Docker Compose дэмждэг нийтийн Linux VPS хэрэгтэй; одоогийн локал `127.0.0.1:8000` хаягийг өөр газраас шууд нээх боломжгүй. Серверийн IP рүү домэйны `A` бичлэг тохируулж, VPS firewall дээр зөвхөн TCP `80`, `443`-ыг нээнэ. Хэрэв `AAAA` бичлэг тохируулсан бол IPv6 firewall мөн зөв байх ёстой. Caddy домэйны TLS гэрчилгээг автоматаар авна.

VPS дээр төслийг татаж байршуулсны дараа төслийн хавтсанд `.env` файл үүсгэнэ (`.env`-ийг хэзээ ч нийтэд байршуулж, commit хийж болохгүй):

```dotenv
DOMAIN=math.example.mn
TEACHER_INVITE_CODE=санамсаргүй-урт-нууц-код
```

`DOMAIN`-ийг өөрийн бодит домэйнээр, `TEACHER_INVITE_CODE`-ийг дор хаяж 32 тэмдэгт санамсаргүй нууц кодоор солино. Нууц үг сэргээх имэйл ажиллуулах бол мөн `.env` дотор `SMTP_HOST`, `SMTP_FROM`, `SMTP_USERNAME`, `SMTP_PASSWORD`-ийг нэмнэ (`SMTP_PORT` анхдагчаар `587`). Эдгээр утгыг эх кодод болон репозиторт бүү хадгал. Жишээ урилгын кодыг сервер дээр Python-оор үүсгэж болно:

```sh
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

Дараа нь сервер дээр:

```sh
docker compose up -d --build
docker compose logs -f caddy
```

Caddy гэрчилгээг амжилттай авсны дараа сурагчдад `https://math.example.mn/` линкийг өгнө. Сервер байнга асаалттай, домэйн зөв IP рүү заасан, гаднаас `80`/`443` нээлттэй байх ёстой. Сурагчид өөрийн имэйлээр бүртгүүлнэ; зөвхөн багшийн бүртгэлд нууц урилгын код хэрэглэнэ. `APP_ENV=production`, `COOKIE_SECURE=1`, бүртгэл хаах хөгжүүлэлтийн нууц үг сэргээх горим унтраалттай байна. SQLite болон байршуулсан материал Docker-ийн `platform-data` эзлэхүүнд хадгалагдана; `docker compose down -v` ажиллуулахад энэ өгөгдөл устах тул өгөгдлийн эзлэхүүнийг тогтмол нөөцөлнө.

### Багш, сурагчийн эхний тохиргоо

1. Серверийг асаагаад `http://127.0.0.1:8000/` хаягийг нээнэ.
2. Багш `Нэвтрэх` → бүртгүүлэх хэсэгт багшийн эрх сонгож, сервер ажиллуулах үеийн `TEACHER_INVITE_CODE`-ийг оруулан бүртгүүлнэ. Бүртгүүлсэн имэйл, нууц үгээрээ дараа нэвтэрнэ.
3. Сурагч мөн өөрийн имэйл, нууц үгээр бүртгүүлнэ. Дараа нь багшийн хэсэгт анги үүсгээд “Сурагч нэмэх”-д тухайн сурагчийн бүртгэлтэй имэйлийг оруулж ангид нэмнэ.
4. Нэвтэрсэн хэрэглэгч зүүн доод талын профайл дээр дарж PNG, JPEG эсвэл WebP зураг (2 MB хүртэл) сонгоно. Зураг `instance/uploads/profiles/` дотор хадгалагдаж, хэрэглэгчийн аватарт харагдана.
5. Профайлын тохиргооноос харагдах нэр, нэвтрэх имэйл болон нууц үгээ өөрчилж болно. Өөрчлөлт хийхэд одоогийн нууц үгийг баталгаажуулна; шинэ нууц үг 12–128 тэмдэгт байна. Нууц үг солиход бусад төхөөрөмжийн сесс гарна, энэ төхөөрөмжид нэвтэрсэн хэвээр үлдэнэ.
6. Багшийн хэсгийн “Цахим хичээлийн явц” хүснэгтээс сурагчийг ангиас хасаж болно. Энэ нь зөвхөн тухайн ангийн гишүүнчлэлийг цуцлах бөгөөд сурагчийн бүртгэл, хадгалсан сурлагын мэдээллийг устгахгүй.
7. Багш нүүр хэсгийн “Нүүр зураг солих” товчоор баннерын зургийг, зүүн цэсний логоны хажуугийн засах товчоор логоны зургийг PNG, JPEG эсвэл WebP форматаар (4 MB хүртэл) байршуулна. Эдгээр зураг сервер болон өгөгдлийн сантай хамт хадгалагдаж, бүх хэрэглэгчид харагдана.

## Бодитой хэрэгжсэн урсгал

- Сурагчийн бүртгэл, багшийн урилгын кодтой бүртгэл, нууц үгийн хэш, HttpOnly cookie сесс, гаралт, сервер талын эрхийн шалгалт.
- Багш ангид бүртгэлтэй сурагчийг имэйлээр нэмнэ; зөвхөн тухайн ангийн эзэмшигч багш энэ үйлдлийг хийж чадна.
- Багш, сурагч өөрийн профайлд зураг upload хийж, серверт хадгална.
- Цахим хичээл: I бүлгийн “Тооны модул”, “Модул агуулсан тэгшитгэл”, “Модул агуулсан тэнцэтгэл биш” гурван дэд сэдвийн онол, томьёо, бодсон жишээ, хэрэглээний бодлого, нэр томьёо, дүгнэлт, сэдэв хоорондын холбоос.
- Цахим хичээл: III бүлгийн “Функц ба график” 7, IV бүлгийн “Функцийн уламжлал” 7 дэд сэдэв; хөтөлбөрийн зорилт, шалгууртай холбосон онол, томьёо, бодсон жишээ, хэрэглээ, нэр томьёо, давтлага, серверээр шалгах мини сорил.
- Цахим хичээл: V бүлгийн “Интеграл” 5, VI бүлгийн “Магадлал ба статистик” 3, VII бүлгийн “Комплекс тоо” 8 дэд сэдэв; хэсэгчлэн интегралчлах, трапецын дүрэм, бином/хэвийн тархалт, комплекс тооны туйлын хэлбэр ба квадрат язгуурыг хамруулсан.
- Цахим хичээлийн хэсгээс MEDLE-ийн XII ангийн нэгж хичээлийн албан хуудсыг шинэ цонхонд нээж, эх платформ дээрх материалыг үзнэ.
- Багш нэвтэрч цахим хичээлийн бүлэг, сэдвээ сонгоод нэмэлт PPT/PPTX, PDF болон MP4/M4V/MOV/WebM/MKV материалыг 100 MB хүртэл байршуулна. Материал сэдэвт хадгалагдаж, PDF нээх, видео хичээлийг тоглуулах, презентац татах боломжтой; багш өөрийн байршуулсан файлаа устгаж болно.
- Модультай тэнцэтгэл бишийн SVG графикийн лаборатори; төв ба зайг slider-аар өөрчлөхөд график, шийдийн завсар бодитоор шинэчлэгдэнэ.
- Хичээл тус бүрийн мини сорил, өдөр тутмын сорилын хариулт сервер дээр оноологдоно; үзсэн хичээл, оноо, алдааны хариулт, хичээл дууссан эсэх SQLite-д хадгалагдана. Мини сорилын 70%-д хүрэхэд тухайн хичээлийг судалсанд тэмдэглэнэ.
- Багш өөрийн ангийн сурагчдын үзсэн/дуусгасан хичээл, сорилын тоо ба алдааны дэлгэрэнгүйг багшийн самбараас харна.
- Томьёоны сан болон нэр томьёоны тайлбар хайлттай; нийтэлсэн материалыг хөтөлбөрийн зорилт, шалгууртай холбож харуулна.
- Нууц үг сэргээх токен; хөгжүүлэлтийн горимд код серверийн консолд гарна. Имэйл хүргэлтэд `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, `SMTP_USERNAME`, `SMTP_PASSWORD` тохируулна.
- Багш анги үүсгэж кодыг нэг удаа авна; сурагч кодоор ангид элсэнэ. Багш дасгал оноож, бодит гүйцэтгэл болон ангийн тоон тайланг харна.
- Багш одоогийн нэгжийн шалгалтыг ангидаа оноож, сурагч оноосон шалгалтаа харах боломжтой.
- Багш сурагчийн дасгалын оноог гараар өөрчилж тайлбар хадгална; сурагчийн хувийн оноо, буруу бодлогын түүх серверээс уншигдана.
- Бүлэг тус бүрийн суурь, стандарт, ахисан түвшний дасгалын сан; I бүлэгт 30, II бүлэгт 12, III бүлэгт 18, IV–VII бүлэгт тус бүр 15 бодлого (нийт 120). Бүлгийн бүх дэд сэдэв дасгалтай. Хариултыг сервер шалгаж, оноо, тайлбар, шалгуур, сурагчийн оролдлогыг SQLite-д хадгална.
- Хөтөлбөрийн бүлэг бүрийн дэлгэрэнгүй картанд тухайн бүлгийн 3 бодлоготой тоглоомон марафон байна. Нэгээс олон өөр сэдэвтэй бодлого санамсаргүй сонгож, хариуг сервер шалган оноо, хурдны бонус, явцыг харуулна; тоглохын тулд сурагчийн эрхээр нэвтэрнэ.
- Нэгжийн хугацаатай шалгалтын оролдлого, серверийн оноолт, нэг удаагийн илгээлт, үр дүнг хадгална.
- Хугацаатай онооны сорил, шат ахих/медалийн суурь дүрэм болон онооны жагсаалт.
- Багшийн `.xlsx` тайлан таталт; хэвлэх цонхоор `PDF болгон хадгалах` тайлан; сурагчийн гар утас/компьютерт тохирох интерфейс.
- `python -m unittest discover -s tests -v` командаар HTTP/API, бүртгэл, эрхийн шалгалт, ангид элсэлт, дасгалын хадгалалт, шалгалтын оноолтын интеграцийн тест ажиллуулна.

## Цахим хичээлийн хадгалалт ба хамрах хүрээ

- Баталгаажсан хичээлийн материал `data/lessons.json`-д, сурагчийн үзэлт/сорилын оролдлого/алдаа `lesson_progress`, `lesson_quiz_attempts`, `lesson_quiz_answers` SQLite хүснэгтүүдэд хадгалагдана. Хуучин SQLite санд сервер эхлэхэд хүснэгтүүд автоматаар нэмэгдэнэ; сургалтын болон хэрэглэгчийн өгөгдөл устахгүй.
- I бүлгийн 3, II бүлгийн 4, III бүлгийн 7, IV бүлгийн 7, V бүлгийн 5, VI бүлгийн 3, VII бүлгийн 8 буюу нийт 37 сэдэв цахим хичээлээр нийтлэгдсэн. III бүлгийн материал 12.3а–12.3д; IV бүлгийн материал 12.7а–12.7в болон шалгуурт туссан 12.7г* зорилтыг хамарна. V–VII бүлгийн хичээлүүд нэгж хөтөлбөрийн суралцахуйн зорилт, үр дүнгийн шалгууртай уялдана.
- Видео эх сурвалж/файл өгөөгүй тул тоглуулагчтай мэт харагдах хуурамч видео нэмээгүй. AI загварын API/зөвшөөрөл тохируулагдаагүй тул AI үйлчилгээ мэт дүр эсгэхгүй. Эдгээр хоёр боломж одоогоор хийгдээгүй.
- Шинэчилсэн хувилбарыг ажиллуулахаас өмнө серверийг зогсоож, дахин `python server.py` эхлүүлнэ. Серверийн код автоматаар restart хийгддэггүй.

### Эх PDF-ийн локал боловсруулалт

- Веб сервер Python стандарт сан ашигладаг хэвээр; PDF/OCR сангууд зөвхөн эх материал боловсруулах хөгжүүлэлтийн хэрэгсэл бөгөөд серверийн runtime хамаарал биш.
- Хөгжүүлэлтийн сангуудыг `python -m pip install -r requirements-dev.txt` командаар суулгана. Монгол OCR-д Tesseract 5 болон `mon` хэлний өгөгдөл шаардлагатай.
- 240 хуудсыг локал OCR-оор унших боломжтойг шалгасан боловч автоматаар сэдэв-хуудастай холбох үр дүн найдвартай биш; бүтэн OCR эх төслийн файлд хадгалагдаагүй.
- Сурах бичгийн PDF текстийн давхаргагүй, вектор дүрстэй тул OCR-ийн томьёо, тэмдэглэгээ, хариуг эх хуудастай тулган хүнээр шалгах ёстой.
- Сурах бичгийн бүтэн эхийг зөвшөөрөлгүйгээр цахимд хуулбарлан нийтлэхгүй. Платформд эхэд нийцсэн, өөрийн найруулгатай тайлбар болон шинээр боловсруулсан жишээ, дасгал оруулна.

## ЭЕШ-сорилын материал нэмэх

- Эх PPTX материалууд `data/eesh_materials/` дотор хадгалагдана; “Сургалт” → “ЭЕШ-сорил” хэсэгт апп дотроо слайдыг үзэж, хариулт/тэмдэглэлээ сурагчийн бүртгэлд хадгалах болон эх PPTX татах боломжтой. Одоогоор 2018 А, 2019 А, 2020 Д, 2021 А, 2022 А хувилбар нэмэгдсэн.
- Эх PPTX бүрийн слайдын JPG дүрсийг `data/eesh_materials/slides/<материалын-ID>/slide-001.jpg` хэлбэрээр хадгалж, `data/eesh_materials.json`-д `slide_count`-ыг эх файлтай нь тааруулан бүртгэнэ. Шинэ материал нэмэхэд ижил форматаар слайдыг локал PowerPoint-оос гаргаж, зөвшөөрөлтэй эх PPTX болон жагсаалтын бичлэгийг хамт нэмнэ.
- Одоогийн PPTX-үүдийн бодолт, дугуйлсан зөв хариу слайд дээр харагддаг тул аппын бөглөх хэсэг нь бэлтгэлийн горим: хариултыг слайд тус бүрд хадгална, оноо автоматаар тавихгүй. Жинхэнэ оноотой шалгалтад асуулт-only материал болон багшийн баталгаажуулсан answer key тусад нь шаардлагатай.
- Интерактив сорилын сан `data/eesh_quizzes.json` файлд тусдаа байна. Шинэчилсний дараа серверийг дахин асаахад сорил он, хувилбараар харагдана.
- Сорил бүр `id` (`eesh-` угтвартай, давхцахгүй), `year`, `variant`, `duration_minutes`, `questions` талбаруудтай. Асуулт бүр давхцахгүй `id`, `prompt`, `answer`, `explanation`, эерэг бүхэл `points`-той байна.
- Хариу хоосон үлдээсэн асуултыг буруу гэж оноолно. ЭЕШ сорилыг зөвхөн сурагчийн эрхээр эхлүүлж, сервер дээр хугацаа, оноо, илгээсэн хариултыг хадгална. Зөв хариу, тайлбарыг шалгалт эхлэхээс өмнө API-аар ил гаргахгүй.
- Эх PPTX файл интерактив асуулт болж хувирахгүй, татах эх материал байдлаар үйлчилнэ. Сорилд нийтлэхийн өмнө асуулт, зөв хариу, тайлбарыг бүтэцтэй JSON өгөгдөл болгон оруулж, эх материалтай тулган шалгана. Нийтлэх эрхтэй материал ашиглана.

## Одоогоор хийгдээгүйг тодорхой тэмдэглэх нь

Энэ бол ажиллагаатай эхний backend болон эхний сэдвийн дасгалын хувилбар; хэрэглэгчийн анхны бүрэн хамрах хүрээ хараахан дуусаагүй.

- Дасгалын сан долоон бүлгийн бүх дэд сэдвийг суурь, стандарт, ахисан түвшнээр хамарна. I бүлэгт 30, II бүлэгт 12, III бүлэгт 18, IV–VII бүлэг тус бүр 15 дасгалтай. Сорил/даалгаврыг бүх сэдэвт 30-аар бүрэн хүргэж нийтлээгүй.
- Үнэн/худал, харгалзуулах, сонголтот, график болон дэлгэрэнгүй бодолттой үнэлгээний төрлүүд бүрэн хэрэгжээгүй.
- PDF нь хөтчийн хэвлэх цонхоор нээгдэж, хэрэглэгч `PDF болгон хадгалах` сонгоно; сервер шууд PDF binary үүсгэхгүй. Медалийн оноо/түвшин нь эхний энгийн дүрэмтэй, тоглоомын бүх төрөл бүрэн хэрэгжээгүй.
- Бүлэг тус бүрт дасгалын сангаас 10 асуулттай, хугацаатай нэгжийн сорил байна. ЭЕШ-сорилын хэсэгт 2018–2022 оны таван PPTX материалыг апп дотор слайд үзэх, хариу/тэмдэглэлээ хадгалах, эх PPTX татах хэлбэрээр нэмсэн; оноотой интерактив ЭЕШ асуултын сан одоогоор хоосон. Шалгасан бодлого, зөв хариу, тайлбарыг `data/eesh_quizzes.json`-д бүтэцтэйгээр оруулахад хугацаат сорил, серверийн оноолт ажиллана. Шинэ нэгжийн шалгалт үүсгэх/нээх/хаах удирдлагын интерфейс хараахан байхгүй. Багшид нэгжийн шалгалтын дүн харагдана; чөлөөт бичилттэй бодлогод автоматаар оноо тавьдаггүй.
- Сурагчийн ахицын график нь туршсан бүлэг болон тухайн бүлгийн нийтлэгдсэн дасгалын хүрээг харуулна.
- Интерактив цахим хичээл, томьёо, тайлбар толь I–VII бүлгийн 37 дэд сэдвийг хамарна. III бүлэгт логарифм, илтгэгч, рационал болон тригонометр функц; IV бүлэгт элементар уламжлал, үржвэр, ноогдвор, тангенс, гинжин дүрэм, параметрт ба далд уламжлал; V бүлэгт тодорхой интеграл, рационал задлал, орлуулга, хэсэгчлэн интегралчлал, трапецын дүрэм; VI бүлэгт дискрет, бином болон хэвийн тархалт; VII бүлэгт комплекс тоон үйлдэл, хосмог, модул, квадрат тэгшитгэл, геометр дүрслэл багтсан.
- Бодит видео материал болон нууцлалын нөхцөл тохируулсан AI үйлчилгээ байхгүй; видео болон AI туслахыг ажиллаж байгаа функц гэж үзэхгүй.
- Гүйцэтгэлийн I–IV түвшний шалгуурыг дасгал бүрд бүрэн уялдуулж нийтлээгүй.
- Одтой нэмэлт зорилтын хамрах хүрээ, эх сурвалжийн хувилбарын тулгалт шаардлагатай хэвээр; 12.2е* тусдаа зорилтын өгүүлбэргүй, 12.8в томьёоны хэлбэр DOCX текстэд алдагдсан. Эдгээрийг таамгаар засварлаагүй.
- Бодит хэрэглээнд нийтлэхээс өмнө эх файлын хувилбар, хөтөлбөрийн шалгуур, бүх бодлогын бодолт ба хариуг багш/мэргэжилтнээр баталгаажуулах шаардлагатай.

## Үйлдвэрлэлийн орчин

Энэ нь нэг машинд ажиллуулах локал эхлэл бөгөөд нийтэд байршуулсан үйлдвэрлэлийн орчин гэж үзэхгүй. Нийтэд байрлуулахын өмнө HTTPS, `COOKIE_SECURE=1`, хүчтэй тогтмол `TEACHER_INVITE_CODE`, `APP_ENV=production`, `ALLOW_CONSOLE_PASSWORD_RESET=0`, SMTP, нөөцлөлт, мониторинг болон найдвартай production HTTP серверийг тохируулна. Багшийн код болон SMTP нууц үгийг эх кодод бичиж болохгүй.

## Эх сурвалж, зөрүү

- 12-р ангийн сурах бичиг, хоёр дахь хэвлэл (240 хуудас).
